Un utilisateur est un compte permettant à une personne de se connecter au système. Un groupe est un ensemble d'utilisateurs qui partagent les mêmes permissions.

<img width="2000" height="1126" alt=",4" src="https://github.com/user-attachments/assets/d0b86ffa-397d-463a-87d9-ab85e9a75d0a" />


Les groupes simplifient la gestion des permissions. Il est plus facile d'attribuer des droits à un groupe qu'à chaque utilisateur individuellement.
