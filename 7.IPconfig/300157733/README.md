La VM Windows Server a été configurée avec une adresse IP statique, une passerelle et un serveur DNS. La connectivité réseau a été vérifiée avec des tests vers la passerelle, Internet et le DNS. Le service Bureau à distance (RDP) a ensuite été activé avec les règles du pare-feu nécessaires. Une connexion distante a été testée pour confirmer l’accès à la VM. Ce laboratoire permet de pratiquer la configuration réseau et l’administration à distance.
