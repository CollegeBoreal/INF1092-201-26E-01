Le but de ce laboratoire était de préparer le réseau de la machine virtuelle Windows Server 2022 et de permettre la connexion à distance. Pour commencer, j’ai vérifié le nom du serveur et les informations du réseau. Ensuite, j’ai donné une adresse IP fixe à la machine, ainsi que le masque, la passerelle et le DNS avec PowerShell. Pour finir, j’ai vérifié que les paramètres étaient bien configurés afin que le serveur puisse se connecter au réseau et être utilisé à distance.
