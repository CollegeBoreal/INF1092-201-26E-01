Ce laboratoire avait pour objectif de se familiariser avec les commandes réseau de PowerShell sous Windows. Les différentes commandes ont permis d'afficher le nom de l'ordinateur, de consulter la configuration IP, de vérifier l'état de la carte réseau et de visualiser les serveurs DNS. Une tentative de configuration d'une nouvelle adresse IP a également été réalisée, puis des tests de connectivité avec la commande ping ont confirmé le bon fonctionnement du réseau
