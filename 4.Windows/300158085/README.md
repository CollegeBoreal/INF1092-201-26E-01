Installation de Windows Server 2022 Datacenter
Objectif

L'objectif de ce laboratoire était d'installer Windows Server 2022 Datacenter sur un serveur HP DL360 G6 et de comprendre les principales étapes de l'installation.

Déroulement du laboratoire

Nous avons commencé par préparer le serveur en vérifiant que le matériel était en bon état et prêt pour l'installation. Nous avons inspecté les différents composants, notamment la mémoire RAM, les disques, les alimentations et les connexions, afin de nous assurer que tout fonctionnait correctement.

Par la suite, nous avons démarré le serveur avec le support d'installation de Windows Server 2022 Datacenter. Nous avons suivi les différentes étapes de l'installation, choisi les options demandées et attendu la fin de la copie et de la configuration des fichiers.

Une fois l'installation terminée, nous avons créé le mot de passe du compte Administrator et ouvert une session sur le serveur. Nous avons ensuite vérifié que le système démarrait correctement, que le réseau fonctionnait et que le serveur était prêt à être utilisé.

Enfin, nous avons effectué une dernière vérification afin de confirmer que l'installation s'était bien déroulée et qu'aucune erreur n'était présente.

Conclusion

Ce laboratoire nous a permis de mieux comprendre le processus d'installation de Windows Server 2022 Datacenter sur un serveur physique. Nous avons appris à préparer le matériel, à réaliser l'installation du système d'exploitation et à effectuer les vérifications nécessaires pour confirmer que le serveur fonctionne correctement.
