RAPPORT D'ATELIER : Installation de Windows Server 2022 Datacenter via PXE

Cours : Introduction à l'administration des systèmes

Étudiant : Azzeddine Ameur (remplace par ton nom si nécessaire)

Objectif

L'objectif de cet atelier était d'installer et de réaliser la configuration initiale de Windows Server 2022 Datacenter en utilisant le démarrage réseau PXE (Preboot Execution Environment). Cette méthode permet de déployer un système d'exploitation sans utiliser de support physique, comme une clé USB ou un DVD, en s'appuyant sur l'infrastructure réseau.

Incident technique

Au cours de l'atelier, notre groupe a rencontré un problème matériel qui a empêché la poursuite de l'installation sur notre serveur. Afin de ne pas interrompre notre apprentissage, j'ai rejoint un autre groupe pour observer les différentes étapes du déploiement et participer à la réalisation des manipulations.

Étapes réalisées
1. Démarrage par le réseau (PXE)

Le serveur a été configuré pour démarrer à partir du réseau (PXE). Cette méthode a permis de lancer automatiquement le programme d'installation de Windows Server 2022.

2. Sélection du système d'exploitation

Nous avons sélectionné l'édition Windows Server 2022 Datacenter afin de procéder à son installation.

3. Déploiement du système

Le processus d'installation comprenait le partitionnement du disque, la copie des fichiers d'installation depuis le serveur de déploiement ainsi que les redémarrages automatiques nécessaires jusqu'à la fin de l'installation.

4. Configuration initiale

Une fois l'installation terminée, nous avons configuré le mot de passe du compte Administrateur, puis nous avons accédé au Gestionnaire de serveur (Server Manager) afin de vérifier que le système était correctement installé et prêt pour les prochaines configurations.

Conclusion

Malgré le problème matériel rencontré par notre groupe, cet atelier m'a permis de comprendre le fonctionnement du déploiement de Windows Server 2022 via PXE. J'ai pu observer les principales étapes de l'installation, depuis le démarrage réseau jusqu'à la configuration initiale du serveur. Cette méthode de déploiement est largement utilisée en entreprise puisqu'elle facilite l'automatisation des installations, réduit le temps de déploiement et simplifie la gestion de plusieurs serveurs.
