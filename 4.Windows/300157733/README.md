# Installation de Windows Server 2022 Datacenter

## Objectif

L'objectif de ce laboratoire était d'installer **Windows Server 2022 Datacenter** sur un serveur **HP DL360 G6** tout en se familiarisant avec les différentes étapes nécessaires à son déploiement sur un serveur physique.

## Déroulement du laboratoire

Dans un premier temps, nous avons préparé le serveur en vérifiant l'état de ses composantes matérielles. Cette étape consistait à inspecter la mémoire vive (RAM), les disques de stockage, les blocs d'alimentation ainsi que les différents câbles et connexions afin de s'assurer que le serveur était prêt pour l'installation.

Nous avons ensuite démarré le serveur à l'aide du support d'installation de **Windows Server 2022 Datacenter**. Au cours de l'installation, nous avons sélectionné les paramètres appropriés, puis laissé le système copier et configurer les fichiers nécessaires avant de procéder aux différentes phases de l'installation.

Une fois le système d'exploitation installé, nous avons configuré le mot de passe du compte **Administrator** et ouvert une première session. Nous avons ensuite effectué plusieurs vérifications pour confirmer le bon fonctionnement du serveur, notamment le démarrage du système, la détection du matériel et le fonctionnement de la connexion réseau.

Enfin, nous avons réalisé une série de contrôles afin de nous assurer que l'installation s'était déroulée sans erreur et que le serveur était entièrement opérationnel.

## Conclusion

Ce laboratoire nous a permis d'acquérir une meilleure compréhension du processus d'installation de **Windows Server 2022 Datacenter** sur un serveur physique. Nous avons appris à préparer le matériel, à installer le système d'exploitation, à effectuer la configuration initiale et à réaliser les vérifications essentielles garantissant le bon fonctionnement du serveur.
