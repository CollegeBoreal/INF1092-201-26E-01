Dans ce laboratoire, l'objectif est d'installer Windows Server 2022 Datacenter sur un serveur HP ProLiant DL360 G6 afin de vérifier s'il peut être utilisé dans un mini centre de données à faible coût. Avant l'installation, une inspection complète du matériel a été effectuée pour s'assurer du bon fonctionnement des composants essentiels tels que le processeur, la mémoire RAM, les disques et les alimentations. Ensuite, l'installation de Windows Server a été réalisée à l'aide du démarrage réseau PXE ou d'une clé USB bootable. Après l'installation, plusieurs configurations ont été effectuées, notamment la définition du mot de passe administrateur, la configuration du réseau, l'attribution d'une adresse IP statique et l'activation de l'accès à distance (RDP). Finalement, des tests de connectivité et de stabilité ont permis de confirmer que le serveur fonctionne correctement et qu'il est prêt à être utilisé dans un environnement réseau.
