Au cours de ce laboratoire, j’ai procédé à l’installation de Windows Server 2022 Datacenter sur un serveur physique. Avant de débuter l’installation, j’ai d’abord vérifié l’état général du matériel afin de m’assurer que tous les composants fonctionnaient correctement. Cette vérification comprenait le processeur (CPU), la mémoire vive (RAM), les disques de stockage ainsi que les différents périphériques nécessaires, comme le clavier, l’écran et la connexion réseau.

Une fois cette vérification terminée, j’ai branché les différents câbles, notamment l’alimentation électrique et le câble réseau (Ethernet). J’ai ensuite démarré le serveur et accédé au menu de démarrage afin de lancer l’installation à l’aide du PXE Boot, qui permet d’installer le système d’exploitation directement à partir du réseau.

Après le chargement de l’environnement d’installation, j’ai sélectionné l’édition Windows Server 2022 Datacenter. J’ai ensuite configuré les paramètres de base, notamment la langue, le format régional et la disposition du clavier. Avant d’installer le système, j’ai préparé le disque en supprimant les anciennes partitions afin d’obtenir une installation propre et d’éviter tout conflit avec des données existantes.

L’installation du système d’exploitation a ensuite été exécutée. Durant cette étape, les fichiers nécessaires ont été copiés sur le disque, les composants de Windows ont été installés et les paramètres initiaux ont été configurés automatiquement. Une fois l’installation terminée, j’ai ouvert une session avec le compte Administrator et j’ai défini un mot de passe sécurisé pour protéger l’accès au serveur.

En résumé, ce laboratoire m’a permis de réaliser toutes les étapes nécessaires à l’installation complète d’un serveur Windows Server 2022 Datacenter, depuis la vérification du matériel jusqu’à la configuration du compte administrateur. Grâce à la méthode d’installation par PXE Boot, à la préparation du disque et aux différents paramètres configurés, le serveur est maintenant pleinement fonctionnel et prêt à recevoir les rôles et services nécessaires dans un environnement informatique professionnel.
