Rapport de laboratoire – Installation d'un disque NVMe

Déroulement
Au cours de ce laboratoire, nous avons procédé à l'installation d'un disque SSD NVMe de 1 To sur un serveur HP DL360 G6 à l'aide d'un adaptateur PCIe. Une fois l'installation physique terminée, nous avons démarré le serveur sous Windows Server 2022 Datacenter afin de vérifier que le nouveau disque était reconnu par le système d'exploitation. Nous avons ensuite effectué son initialisation, créé une partition, réalisé le formatage et effectué quelques vérifications pour nous assurer que le disque fonctionnait correctement.
