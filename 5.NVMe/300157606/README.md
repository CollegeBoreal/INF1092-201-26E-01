Rapport de laboratoire – Installation d'un disque NVMe

Introduction:
Dans ce laboratoire, nous avons installé un disque NVMe de 1 To sur un serveur HP DL360 G6 à l'aide d'un adaptateur PCIe. Après l'installation du matériel, nous avons démarré Windows Server 2022 Datacenter pour vérifier que le disque était bien reconnu. Ensuite, nous avons initialisé le disque, créé une partition et effectué le formatage. Enfin, nous avons réalisé quelques tests afin de confirmer que le disque fonctionnait correctement.

  

Objectif: L'objectif de ce laboratoire est d'installer un disque NVMe de 1 To sur un serveur afin d'augmenter la capacité de stockage et d'améliorer les performances du système.



Étapes d'installation:

1. Préparation du matériel

    Avant de commencer, nous avons éteint le serveur et débranché son alimentation pour travailler en toute sécurité. Nous avons également vérifié que le serveur était compatible avec un disque NVMe grâce à un adaptateur PCIe.

2. Installation du disque

    Le disque NVMe a été installé sur l'adaptateur PCIe, puis l'adaptateur a été inséré dans le serveur. Après avoir fixé les composants, nous avons refermé le boîtier et rebranché le serveur.

3. Vérification du disque

    Au démarrage, nous avons accédé au BIOS pour vérifier que le disque NVMe était bien détecté. Cette vérification permet de confirmer que l'installation physique a été réalisée correctement.

4. Configuration du disque

    Une fois Windows Server démarré, nous avons initialisé le disque, créé une nouvelle partition et effectué le formatage afin de le rendre prêt à être utilisé.

5. Validation

    Pour terminer, nous avons vérifié que le disque apparaissait correctement dans Windows et réalisé un test de lecture et d'écriture pour confirmer son bon fonctionnement.


Conclusion:Ce laboratoire nous a permis d'apprendre à installer un disque NVMe sur un serveur HP DL360 G6. Après l'installation et la configuration, le disque a été reconnu sans problème et fonctionne correctement. Cette opération permet d'améliorer la capacité de stockage et les performances du serveur.
