L’objectif de ce laboratoire était de mettre en place une machine virtuelle Windows Server 2022 à l’aide de Hyper-V. Pour commencer, j’ai téléchargé le fichier ISO de Windows Server 2022 à partir d’Azure Education et je l’ai sauvegardé dans mon dossier personnel, sur le lecteur D:\ISO.

Ensuite, j’ai créé une machine virtuelle de génération 1 avec les paramètres demandés. J’ai configuré 4 Go de mémoire vive, 2 processeurs, un disque dur virtuel de 60 Go et une connexion réseau de type External. Après cela, j’ai associé le fichier ISO à la machine virtuelle, puis je l’ai démarrée afin de vérifier que l’installation de Windows Server 2022 fonctionnait correctement.

Pour terminer, j’ai utilisé des commandes PowerShell afin de vérifier les différents paramètres de la machine virtuelle, notamment la mémoire, le nombre de processeurs, la taille du disque et la configuration réseau.
