Ce laboratoire consiste à créer une machine virtuelle Windows Server 2022 dans Hyper-V en respectant les exigences du laboratoire. L'objectif est de télécharger l'image ISO depuis Azure Education, de créer une VM Génération 1 avec 4 Go de RAM fixe, 2 processeurs, un disque de 60 Go et un réseau External, puis de monter l'ISO et de démarrer l'installation de Windows Server. Enfin, il faut vérifier que la configuration de la machine virtuelle est correcte (CPU, mémoire, disque et réseau) et que l'installation démarre normalement.
