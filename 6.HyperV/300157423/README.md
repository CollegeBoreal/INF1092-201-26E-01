Ce travail consiste à créer une machine virtuelle Windows Server 2022 dans Hyper-V, en utilisant un fichier ISO téléchargé depuis Azure Education. La VM est configurée avec les paramètres demandés (GEN1, 4 Go de RAM, 2 CPU, disque de 60 Go) afin de démarrer et vérifier le bon fonctionnement de Windows Server.
