Étape 1 : Vérification du matériel

Nous avons commencé par vérifier le matériel du serveur, notamment le processeur (CPU), la mémoire RAM, les disques, les câbles d’alimentation et la connexion réseau. Cette étape permet de s’assurer que le serveur est prêt pour l’installation.

Étape 2 : Branchement des périphériques

Nous avons branché les périphériques nécessaires, comme l’écran, le clavier et la souris, puis nous avons connecté le câble d’alimentation et le câble réseau.

Étape 3 : Démarrage du serveur

Nous avons allumé le serveur et vérifié qu’il démarrait correctement sans erreur matérielle.

Étape 4 : Accès au BIOS

Nous sommes entrés dans le BIOS afin de vérifier les paramètres du serveur et de modifier l’ordre de démarrage.

Étape 5 : Choix du périphérique de démarrage

Nous avons sélectionné la clé USB (ou le démarrage PXE, selon le laboratoire) comme premier périphérique de démarrage pour lancer l’installation de Windows Server 2022.

Étape 6 : Installation de Windows Server

Nous avons choisi la langue, le clavier, l’édition Windows Server 2022 Datacenter, puis sélectionné le disque de destination. Les anciennes partitions ont été supprimées avant de lancer l’installation.

Étape 7 : Configuration du compte administrateur

Après l’installation, nous avons créé un mot de passe sécurisé pour le compte Administrator et ouvert une session.

Étape 8 : Vérification finale

Enfin, nous avons confirmé que Windows Server était installé correctement et que le serveur fonctionnait normalement, prêt à recevoir les configurations et les rôles nécessaires.
