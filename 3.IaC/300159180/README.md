Démontage et remontage d’un serveur HP ProLiant DL380 G6

Dans le cadre de ce laboratoire, j’ai effectué le démontage complet, puis le remontage d’un serveur HP ProLiant DL380 G6 afin de me familiariser avec ses principaux composants matériels et leur installation.

J’ai commencé par retirer les deux blocs d’alimentation redondants situés à l’arrière du serveur. Après avoir ouvert le châssis, j’ai retiré les disques durs SAS, les ventilateurs hot-swap, puis les dissipateurs thermiques et les deux processeurs en prenant soin de les manipuler uniquement par les côtés afin d’éviter d’endommager les contacts.

Une fois tous les composants démontés, j’ai procédé au remontage en respectant l’ordre inverse. J’ai réinstallé les processeurs dans leurs sockets, replacé les dissipateurs thermiques, remis les ventilateurs à leur emplacement respectif, réinstallé les disques durs SAS, puis refermé le châssis. Le serveur a ensuite été replacé dans la baie à l’aide des rails de montage.

Pour terminer, j’ai raccordé le câble VGA pour l’accès à la console ainsi que les câbles d’alimentation. J’ai également vérifié la connectivité du serveur avec le commutateur Cisco installé dans le rack afin de confirmer le bon fonctionnement de l’équipement après le remontage.

Ce laboratoire m’a permis d’acquérir une meilleure compréhension de l’architecture interne d’un serveur et des bonnes pratiques de maintenance. J’ai retenu qu’il est essentiel de travailler de manière méthodique, de respecter l’ordre de démontage et de remontage des composants, de ne jamais forcer les connecteurs et de manipuler les processeurs avec précaution afin d’éviter tout dommage matériel.
