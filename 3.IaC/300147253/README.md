Après avoir terminé l'assemblage du matériel, nous avons procédé à l'installation du système d'exploitation sur le serveur. Dans un premier temps, nous avons vérifié les principaux composants matériels, notamment les processeurs, la mémoire RAM et les disques durs, afin de nous assurer qu'ils étaient correctement installés et reconnus.

Nous avons ensuite connecté les périphériques nécessaires, tels que l'écran, le clavier, la souris et les câbles d'alimentation. Une fois le serveur démarré, nous nous sommes connectés à l'interface de gestion en saisissant les informations d'authentification requises (nom d'utilisateur et mot de passe).

Après avoir obtenu l'accès au serveur, nous avons configuré l'ordre de démarrage (Boot Order) afin de lancer le système à partir de la clé USB contenant les fichiers d'installation du système d'exploitation. Cette configuration a permis de démarrer l'installateur et de commencer le processus d'installation.
